# SLIIT DevOps Workshop

Welcome to the SLIIT DevOps Workshop! This repository contains practical examples and hands-on exercises to learn key DevOps concepts and tools.

## Workshop Overview

This workshop covers the following essential DevOps topics:

1. **Docker** - Containerization basics
2. **Docker Compose** - Multi-container applications
3. **GitHub Actions** - CI/CD pipelines
4. **Terraform** - Infrastructure as Code

## Prerequisites

- Basic knowledge of command line
- Git installed on your machine
- Docker and Docker Compose installed
- A GitHub account
- Terraform installed (for the Terraform section)

## Workshop Structure

```
├── 01-docker/           # Docker fundamentals
├── 02-docker-compose/   # Multi-container applications
├── 03-github-actions/   # CI/CD with GitHub Actions
└── 04-terraform/        # Infrastructure as Code
```

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/njay4928/sliit-devops-workshop.git
   cd sliit-devops-workshop
   ```

2. Follow the exercises in order, starting with the Docker section.

## Learning Objectives

By the end of this workshop, you will:
- Understand containerization with Docker
- Build and manage multi-container applications
- Create automated CI/CD pipelines
- Deploy infrastructure using code
- Apply DevOps best practices
